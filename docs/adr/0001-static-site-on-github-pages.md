# 0001. 서버 없는 정적 사이트를 GitHub Pages로 배포한다

- 상태: 채택
- 날짜: 2026-02-08 (Jekyll로 시작), 2026-08-26 Astro 이전 후에도 유지

## 배경
개인 학습 블로그다. 운영 인력은 한 명이고, 비용과 관리 부담이 작아야 한다. 글과 데이터는 이미 Git 저장소에 있다.

## 결정
서버와 데이터베이스 없이 빌드 시점에 HTML을 모두 만들고, GitHub Pages로 배포한다. 빌드와 배포는 GitHub Actions가 `main` 푸시 때 실행한다.

## 검토한 대안
- **Vercel / Netlify / Cloudflare Pages**: 응답 헤더, 리다이렉트, 미리보기 배포를 쓸 수 있다. 저장소 밖에 계정과 설정이 하나 더 생기고, 지금은 그 기능이 필요 없다.
- **자체 서버(VPS)**: 동적 기능을 넣을 수 있지만 보안 패치와 운영 부담이 블로그 규모에 비해 크다.

## 결과
- 비용 0, 저장소 하나로 관리가 끝난다.
- GitHub Pages는 응답 헤더를 설정할 수 없어 CSP 같은 보안 헤더를 쓸 수 없고, 서버 리다이렉트도 없다. URL을 바꾸면 이전 주소는 깨진다.
- 다시 볼 조건: 보안 헤더나 리다이렉트가 필요해지면 Cloudflare Pages로 옮긴다.
