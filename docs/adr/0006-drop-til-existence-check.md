# 0006. 빌드 시 TIL 경로 존재 확인(GitHub API)을 제거한다

- 상태: 채택
- 날짜: 2026-10-11

## 배경
기술에 연결한 TIL 경로(`MY_PJT/TIL/...`)가 실제로 있는지 빌드 때마다 GitHub API로 확인하고, 없으면 독자 화면에 `unverified` 배지를 붙였다. 확인해 보니 문제가 있었다.
- 빌드가 네트워크와 API 한도에 의존한다. 토큰 없이 로컬에서 빌드하면 시간당 60회 한도에 걸린다.
- 같은 확인을 페이지마다 반복했다. 노드 페이지마다 약 300ms가 걸렸다.
- 결과가 독자에게만 보이고, 고쳐야 할 작성자에게는 알림이 없었다.
- 이를 위해 배포 워크플로가 빌드에 `GITHUB_TOKEN`을 넘기고 있었다.

## 결정
확인 코드와 토큰 전달을 모두 뺀다. TIL 링크는 그대로 생성한다.

## 결과
- 빌드가 오프라인으로도 결정적으로 동작하고, 빌드 과정에 토큰이 노출되지 않는다.
- 경로를 잘못 적어도 사이트가 알려주지 않는다. TIL 링크는 몇 개뿐이라 감수한다.
- 다시 볼 조건: TIL 링크가 많아지면 독자 화면이 아니라 CI의 링크 검사로 되살린다.
