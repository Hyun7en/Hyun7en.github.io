# 0014. 다크 모드는 OS 설정을 따르고 토글은 두지 않는다

- 상태: 채택
- 날짜: 2026-10-11

## 배경
블로그는 라이트 테마만 있었고, 그래서 giscus 테마도 `light`로 고정했다([0011](0011-comments-giscus.md)). 밤에 오래 읽는 개발 블로그인데 OS가 다크 모드인 방문자에게도 밝은 화면을 보여 준다.

## 결정
- `@media (prefers-color-scheme: dark)`에서 CSS 변수만 바꾼다. 토글과 저장 기능은 두지 않는다.
- 흰 글자가 올라가는 채움 색(버튼, 눌린 필터, 개수 배지)은 `--color-primary-solid`로 분리해 두 테마에서 같은 진한 파랑을 쓴다. 링크와 글자에 쓰는 `--color-primary`는 다크에서 밝게 바꾼다.
- giscus 테마는 `preferred_color_scheme`으로 바꿔 페이지와 함께 전환한다.

## 검토한 대안
- **토글 + localStorage**: 사용자가 OS와 다르게 고를 수 있다. 하지만 첫 렌더링 전에 테마를 정하는 인라인 스크립트가 필요하고, 그러지 않으면 화면이 깜빡인다. giscus에 테마를 전달하는 postMessage도 필요하다. 지금 규모에서는 이 비용을 들일 이유가 없다.

## 결과
- 클라이언트 JS 추가 없이 두 테마를 지원한다. axe 대비 검사는 두 테마 모두 통과한다.
- 다시 볼 조건: 토글 요청이 있거나, OS 설정과 다른 테마를 원하는 독자가 많을 때.
