# 0012. AI 코딩 규칙을 이 저장소에만 적용한다

- 상태: 채택
- 날짜: 2026-10-11

## 배경
AI 코딩 도구(Claude Code)로 작업할 때 두 가지를 막고 싶었다. 요청보다 큰 변경과, 검증 없이 "완료"라고 하는 것이다. 두 가지 공개 규칙을 쓰기로 했는데, 다른 프로젝트에는 영향을 주지 않아야 했다.

## 결정
저장소 안 `.claude/`에 둔다. 이 저장소로 작업하는 세션에서만 읽힌다.
- `.claude/rules/karpathy.md`: `forrestchang/andrej-karpathy-skills`의 가이드라인. 가정 먼저 밝히기, 최소 코드, 요청받은 줄만 수정.
- `.claude/skills/verification-before-completion/SKILL.md`: `obra/superpowers`의 스킬. 검증 명령의 출력을 확인하기 전에는 완료라고 하지 않는다.
- `.claude/rules/verification.md`: 스킬이 호출되지 않아도 적용되도록 같은 내용을 한 줄로 둔다.

공급망 위험을 줄이기 위해 원본은 특정 커밋(SHA)에 고정해서 받았다. 각 파일 맨 위에 출처와 SHA를 남겼고, 넣기 전에 전체 내용을 읽어 의심스러운 지시가 없는지 확인했다.

## 검토한 대안
- **사용자 전역(`~/.claude/`)**: 모든 프로젝트에 적용되어 원하는 범위보다 넓다. 클라우드 세션에도 따라오지 않는다.

## 결과
- 로컬과 클라우드 세션 모두 같은 규칙으로 작업한다(`main` 머지 후).
- 원본이 업데이트돼도 자동으로 따라가지 않는다. 갱신할 때는 새 SHA로 다시 받고 차이를 확인한다.
